# PRD — 제품 요구사항 문서

작성일: 2026-11-04

## 배경과 목표

마우스나 손가락으로 쓴 숫자 하나(0~9)를 즉시 인식해 보여주는 프로그램이다. 코딩 초보자가 신경망의 학습부터 웹 배포까지 전 과정을 직접 경험하는 것이 목적이다.

**목표**

- 손글씨 숫자를 높은 정확도로 인식하는 데스크톱 프로그램
- 같은 기능을 웹 브라우저에서 쓸 수 있는 웹 버전
- 인터넷 주소로 누구나 접속할 수 있는 무료 배포(GitHub Pages)

**비목표**

- 여러 자리 숫자나 문자 인식
- 사용자 계정, 그림 저장 등 서버가 필요한 기능

## 대상 사용자와 사용 시나리오

주 사용자는 프로젝트를 만든 코딩 초보자 본인과, 공유 링크를 받은 일반 방문자다.

1. 사용자가 검은 그림판에 숫자 하나를 그린다.
2. 마우스나 손가락을 떼면 인식된 숫자, 확신도, 0~9 확률이 바로 나타난다.
3. '지우기'를 누르고 다른 숫자를 그려 본다.

## 비기능 요구사항

- **코드 규칙**: 코드는 영어, 주석은 한글로 작성한다.
- **의존성 최소화**: 파이썬은 NumPy와 Pillow만, 웹은 외부 라이브러리 없이 만든다.
- **서버 없음**: 웹 버전은 정적 파일만으로 동작해 GitHub Pages에 무료로 올릴 수 있어야 한다.
- **응답 속도**: 인식은 브라우저 안에서 네트워크 요청 없이 즉시 끝난다.
- **환경**: Windows 11, Python 3.13에서 확인했다. 웹은 최신 브라우저와 터치 기기를 대상으로 한다.
